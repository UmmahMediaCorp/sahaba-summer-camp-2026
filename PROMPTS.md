## Workflow with OpenAI image gen 2.0

1. Open https://platform.openai.com/playground or the ChatGPT image gen UI
2. **Attach all 3 printed posters** (`assets/posters/poster-syc.jpg`, `poster-downtown.jpg`, `poster-alfaruq.jpg`) as **style reference images** for the poster-style prompts
3. Paste the prompt
4. Set aspect ratio per the heading
5. For photoreal prompts, *don't* attach the posters — just generate

Save outputs as the filenames above into `assets/images/` (replacing existing JPGs and WebPs), then run:

```bash
cd assets/images
for f in *.jpg; do
  cwebp -q 78 -m 6 -mt -af "$f" -o "${f%.jpg}.webp"
done
```

then `git add -A && git commit -m "swap in OpenAI-generated images" && git push` — Vercel auto-redeploys.
